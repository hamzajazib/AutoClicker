# ZClicker Changelog

## Version 1.1.0

ZClicker’s biggest update yet, focused on automation, customization, reliability, and speed.

### Free

- Refreshed the main interface.
- Added previews of ZClicker Pro features.
- Improved clicking reliability.
- Improved layout and control consistency.
- Added automatic update notifications.

### Pro

- Added Macro Recorder with a visual action timeline and editor.
- Added Count, Toggle, and While Held macro playback modes.
- Added separate customizable recording and playback hotkeys.
- Added Presets for saving complete clicker setups and macros.
- Added Dark, Light, and System appearance modes.
- Added an emergency Esc hotkey.
- Added automatic update notifications with release notes.
- Improved startup speed and reduced application size.
- Moved application data to AppData.
- Fixed settings persistence and feature-switching reliability.
- Improved Background Window Clicker and Click Position reliability.
